# Architecture decision workflow

```text
Boundary or durable design decision
  → gather repository evidence
  → @architect + impact-analysis
  → compare existing pattern and alternatives
  → record context, decision, consequences, and rejected options
  → identify migration, rollback, and review date
  → validate against current implementation
```

## Hard rules

- Prefer an existing ADR convention.
- Record decisions, not speculative design essays.
- Update or supersede stale decisions when the architecture changes.
